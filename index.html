Häufige Fragen

Bevor du fragst.

Was kostet ein System von Onyx?

Jedes System ist individuell — deshalb gibt es keinen Katalogpreis. Nach dem ersten Gespräch bekommst du ein klares Konzept mit Festpreis, bevor irgendetwas programmiert wird.

Wie lange dauert der Bau?

Kommt auf den Umfang an. Ein fokussiertes Tool kann in wenigen Wochen stehen, ein komplettes CRM wie HausManager Pro dauert länger. Im Erstgespräch bekommst du eine realistische Einschätzung für dein Projekt.

Muss ich technisch versiert sein?

Nein. Du beschreibst deinen Prozess, ich übersetze ihn in ein System. Zur Übergabe bekommst du eine verständliche Dokumentation — keine Entwickler-Fachsprache.

Was, wenn ich später Änderungen brauche?

Du besitzt den Code vollständig — jeder Entwickler kann daran weiterarbeiten, auch ohne mich. Willst du, dass ich die Änderungen mache, meldest du dich einfach wieder.

Können mehrere Personen das System nutzen?

Ja. Dein System bekommt ein eigenes Login, das komplett dir gehört. Du kannst darin selbst weitere Accounts anlegen — zum Beispiel für dein Team. Jeder loggt sich mit seinem eigenen Zugang ein und sieht genau das, was für ihn relevant ist.

Ist mein System DSGVO-konform?

Ja. Du hostest selbst, in Deutschland bzw. der EU, mit AVV. Es laufen keine Daten über fremde Server, die du nicht kontrollierst.
